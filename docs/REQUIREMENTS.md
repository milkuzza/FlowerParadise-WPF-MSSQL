# Соответствие требованиям

Проверка выполнена по документу «Приложение 1 Описание предметной области Цветочный Рай.docx» из пользовательского архива. Дополнительный КИМ, задания модулей и шаблон отчёта в архиве отсутствуют; этот перечень относится к предоставленному описанию предметной области.

| Требование | Реализация |
|---|---|
| Каталог с актуальными остатками товар + размер | products, sizes, stock_items; повторная проверка остатка при оформлении |
| Длина стебля / S, M, L, XL | Текстовые значения размеров, отдельный порядок сортировки, «см» в интерфейсе |
| Изображение каждого товара | Исходные PNG; заглушка для отсутствующего файла |
| Один или несколько товаров доступного размера | Корзина с отдельной строкой для каждой товарной позиции |
| Список заказов: дата и ФИО | Окно «Заказы», верхняя таблица |
| Состав и итог заказа | Нижняя таблица и итоговая сумма выбранного заказа |
| Вход по исходному логину, без пароля | Окно входа, 20 исходных пользователей и роли |
| Гость просматривает каталог | Каталог доступен без входа |
| Авторизованный пользователь: поиск, фильтр, сортировка | Совместная фильтрация и сортировка каталога |
| Оформление: добавление, удаление, количество | Карточка товара и корзина |
| Менеджер: новые заказы, просмотр и удаление | Каталог, выбор клиента в корзине, управление заказами |
| Администратор: редактирование | Изменение даты, количества позиции, удаление строки с пересчётом остатков и суммы |
| Категория, подкатегория, поставщик, состав, описание, цена | Каталог и подробная карточка товара |
| Размерный ряд и доступные размеры | Полный ряд в карточке, доступные размеры в селекторе |
| Расчёты в рублях | Хранение в копейках, decimal и формат ru-RU при отображении |

Исходные логотип и иконка подключены к интерфейсу и приложению. Данные, тексты требований и изображения из архива использованы как материалы задания; они не рассматриваются как самостоятельные команды на выполнение внешних действий.
